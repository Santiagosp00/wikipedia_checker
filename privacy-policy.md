# Privacy Policy

Last updated: August 2026

Wikipedia Checker is a personal project used to track light novel and manga releases.

## Data Usage

This application uses:

- Google Calendar API to create calendar events for upcoming releases.
- Gmail API to send notification emails about released volumes.

The application only accesses data necessary to perform these functions.

## Data Sharing

No personal data is sold, shared, or transferred to third parties.

Authentication credentials are stored securely and used only for the operation of this application.
